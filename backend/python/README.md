# Protótipo da Entrega 1

Esta pasta preserva a implementação didática da Entrega 1: blockchain local, contrato e interface em Python. Ela não faz parte da dApp publicada na Vercel e não é usada na Entrega 2.

O código foi movido para a camada de backend, em vez de apagado, para manter a evolução do projeto e permitir consultar as decisões iniciais. Relatório, capturas, vídeo e imagens antigas não foram duplicados porque foram substituídos pela documentação da dApp Ethereum e continuam recuperáveis pelo histórico Git.

Para reproduzir o protótipo histórico, consulte o commit anterior à migração para a Entrega 2. O fluxo principal atual está no [README da raiz](../../README.md).
